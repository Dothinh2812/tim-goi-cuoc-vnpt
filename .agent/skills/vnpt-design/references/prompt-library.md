# THƯ VIỆN PROMPT AI CHO THIẾT KẾ VNPT

## Cách dùng thư viện này
Mỗi prompt được thiết kế cho các công cụ AI như:
- **Canva AI** (Magic Design, Text to Image)
- **Adobe Firefly**
- **Midjourney / DALL-E**
- **Leonardo AI**
- **Ideogram**

Prompt tiếng Anh cho image generation (hiệu quả hơn), mô tả thiết kế tiếng Việt cho Canva Magic Design.

## THÔNG SỐ NEGATIVE PROMPT (Cho Midjourney/Stable Diffusion)
*Thêm vào cuối mỗi prompt để loại bỏ yếu tố không phù hợp:*
```
--no text, watermark, logo, letters, words, blurry, low quality, 
dark moody atmosphere, horror, violence, 
green color dominance, red color dominance, 
cartoon childish style, anime, sketch, pencil drawing,
cluttered busy background, realistic photo (nếu cần flat design)
```

## MẸO DÙNG CANVA AI (Magic Design)
1. Dùng tab "Tạo hình ảnh" → nhập mô tả tiếng Việt
2. Chọn style "Flat design" hoặc "Illustration"
3. Sau khi có ảnh → điều chỉnh màu về đúng bảng màu VNPT
4. Dùng công cụ "Chỉnh màu thương hiệu" để lock màu #003399, #0099CC, #FF6600
5. Lưu bộ màu VNPT vào Brand Kit của Canva workspace
