This folder stores legacy source files that are not part of the current Astro app runtime.

Groups:
- `legacy-static-site/`: old root HTML pages, old blog HTML, and old static JS/CSS from the pre-Astro site
- `migration-tools/`: one-off scripts used to convert old files into the current Astro structure
- `reference-materials/`: source docs and planning files kept for reference
- `side-projects/`: separate experiments not used by the current Astro app
