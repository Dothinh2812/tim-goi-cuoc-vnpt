# TEMPLATE THIẾT KẾ THEO LOẠI BÀI ĐĂNG

## TEMPLATE 1: INFOGRAPHIC MẸO / HƯỚNG DẪN
*(Dùng cho bài Education – Bác sĩ WiFi, Thủ thuật máy tính...)*

### Bố cục (1080×1080px)
```
┌─────────────────────────────────────────┐
│ [LOGO VNPT]              [BADGE: MẸO]   │  ← Header 15%: nền #003399, chữ trắng
│ TIÊU ĐỀ LỚN – TỐI ĐA 8 CHỮ            │
├─────────────────────────────────────────┤
│                                         │
│  [ICON 1]   Nội dung điểm 1            │  ← Body 70%: nền trắng hoặc #F5F7FA
│  [ICON 2]   Nội dung điểm 2            │     Text màu #1A1A2E
│  [ICON 3]   Nội dung điểm 3            │     Icon màu #003399 hoặc #0099CC
│  [ICON 4]   Nội dung điểm 4            │
│                                         │
├─────────────────────────────────────────┤
│  [WAVE PATTERN]    📞 Hotline / Logo   │  ← Footer 15%: nền gradient xanh
└─────────────────────────────────────────┘
```

### Màu sắc áp dụng
- Header background: `#003399`
- Badge/Label: `#FF6600`
- Body background: `#FFFFFF` hoặc `#F5F7FA`
- Icon accent: `#0099CC`
- Text chính: `#1A1A2E`
- Footer gradient: `#003399 → #0099CC`

### Yếu tố bắt buộc
- Logo VNPT (góc trên trái, white version)
- Badge loại nội dung (MẸO / CẢNH BÁO / HƯỚNG DẪN)
- Wave pattern ở footer hoặc góc dưới
- Tối đa 5 điểm nội dung

## TEMPLATE 2: CẢNH BÁO / THÔNG BÁO QUAN TRỌNG
*(Dùng cho bài An toàn số, Cảnh báo lừa đảo...)*

### Bố cục (1080×1080px)
```
┌─────────────────────────────────────────┐
│         ⚠️  CẢNH BÁO                   │  ← Header 20%: nền đỏ cam #CC2200
│    TIÊU ĐỀ NGẮN GỌN TẠO IMPACT        │    hoặc nền xanh đậm #003399 + icon ⚠️
├─────────────────────────────────────────┤
│                                         │
│   [VISUAL MINH HỌA TRUNG TÂM]          │  ← Body 55%: ảnh minh họa
│   (điện thoại + tin nhắn lừa đảo,      │    hoặc flat illustration
│    icon khóa bị phá, v.v.)             │
│                                         │
├─────────────────────────────────────────┤
│  ✅ Cách nhận biết / Cách phòng tránh  │  ← Info box 25%: nền #F5F7FA
│  1. ...  2. ...  3. ...                │    Text ngắn gọn, icon ✅❌
├─────────────────────────────────────────┤
│  [LOGO VNPT]    Sơn Tây bình an 🛡️    │  ← Footer: gradient xanh
└─────────────────────────────────────────┘
```

### Màu sắc áp dụng
- Header cảnh báo: `#CC2200` (đỏ) hoặc `#003399` + icon warning
- Visual area: trắng hoặc xám nhạt `#F5F7FA`
- Highlight quan trọng: `#FF6600`
- Text thân: `#1A1A2E`

## TEMPLATE 5: KHUYẾN MÃI / ƯU ĐÃI
*(Dùng cho bài Promotion)*

### Bố cục (1080×1080px)
```
┌─────────────────────────────────────────┐
│  [LOGO]    🎉 ƯU ĐÃI ĐẶC BIỆT         │  ← Header: #003399
├─────────────────────────────────────────┤
│                                         │
│     [BADGE CAM lớn: -30% / TẶNG 2T]   │  ← Badge nổi bật: #FF6600
│                                         │
│     TÊN GÓI CƯỚC                       │  ← Headline: Trắng, Bold
│     Lợi ích 1 | Lợi ích 2 | Lợi ích 3 │  ← Subtext: #0099CC
│                                         │
│     Chỉ từ XXX.000đ/tháng             │  ← Giá: to, trắng, đóng khung cam
│                                         │
├─────────────────────────────────────────┤
│   [Wave pattern]  📞 Hotline VNPT      │  ← Footer: gradient
│   Ưu đãi đến hết: DD/MM/YYYY          │
└─────────────────────────────────────────┘
```

### Yếu tố bắt buộc bài Promotion
- Badge giá / ưu đãi màu cam `#FF6600` — phải nổi bật nhất
- Giá tiền rõ ràng, to
- Thời hạn ưu đãi
- Hotline hoặc link đăng ký

## GHI CHÚ CHUNG CHO MỌI TEMPLATE

### Checklist trước khi xuất file
- [ ] Logo VNPT đúng phiên bản (trắng trên nền xanh / màu trên nền sáng)
- [ ] Màu chủ đạo #003399 chiếm ít nhất 60% diện tích
- [ ] Không có thông số kỹ thuật thuần túy (phải là lợi ích)
- [ ] Text đủ lớn để đọc trên điện thoại
- [ ] Wave pattern hoặc orbit line xuất hiện ít nhất 1 lần
- [ ] Footer luôn có logo + hashtag/hotline
- [ ] Badge cam #FF6600 chỉ dùng khi có 1 điểm nhấn quan trọng nhất
