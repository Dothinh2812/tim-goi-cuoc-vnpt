## Gradient chuẩn VNPT
```
Linear gradient: 135deg → #003399 đến #0099CC
Radial gradient: #0099CC (tâm) → #003399 (rìa)
Overlay trên ảnh: rgba(0, 51, 153, 0.75) → rgba(0, 153, 204, 0.5)
```

## Typography (Chữ viết)

### Font chính thức
- **Headlines**: Helvetica Neue Bold / Arial Bold — IN HOA hoặc Sentence Case
- **Subheadline**: Helvetica Neue Medium / Open Sans SemiBold
- **Body text**: Helvetica Neue Regular / Open Sans Regular / Roboto Regular
- **Caption / Label**: Open Sans Regular, cỡ nhỏ hơn

### Cỡ chữ khuyến nghị (Facebook post 1080×1080px)
| Thành phần | Cỡ | Weight |
|---|---|---|
| Headline chính | 52-72px | Bold |
| Subheadline | 32-42px | SemiBold |
| Body text | 22-28px | Regular |
| Caption | 16-20px | Regular |
| Badge / Label | 18-24px | Bold |

### Màu chữ theo nền
| Nền | Màu chữ chính | Màu chữ phụ |
|-----|---------------|-------------|
| Nền xanh #003399 | #FFFFFF | #0099CC |
| Nền trắng | #1A1A2E | #003399 |
| Nền gradient | #FFFFFF | #FFFFFF với opacity 80% |
| Nền ảnh (overlay xanh) | #FFFFFF | #FFFFFF |

## Logo VNPT – Quy tắc đặt vị trí

### Vị trí ưu tiên trong thiết kế
- **Post vuông (1080×1080)**: Góc trên trái hoặc góc trên phải
- **Post ngang (1200×628)**: Góc trên trái
- **Story/Reels (1080×1920)**: Góc trên giữa hoặc góc trên trái
- **Banner dài**: Bên trái, cạnh headline

### Khoảng cách an toàn (Clear Space)
- Xung quanh logo: tối thiểu bằng chiều cao chữ "V" trong logo
- Thực tế: padding tối thiểu 24-32px mỗi phía

### Phiên bản logo theo nền
| Nền | Dùng phiên bản |
|-----|----------------|
| Nền trắng / sáng | Logo màu xanh #003399 (Positive) |
| Nền xanh đậm | Logo trắng (Negative) |
| Nền ảnh tối | Logo trắng |
| Nền gradient | Logo trắng |

## Design Elements đặc trưng VNPT

### 1. Sóng viễn thông (Wave Pattern)
Ba vòng cung uốn lượn, độ đậm giảm dần từ trong ra ngoài.
```
Màu: #0099CC với opacity 15–40%
Góc đặt: góc dưới phải hoặc dưới trái
Kích thước: 30–50% diện tích thiết kế
```

### 2. Đường orbit (Orbit Lines)
Đường elip mỏng bao quanh element chính, tượng trưng vệ tinh quay quanh địa cầu.
```
Màu: #0099CC với opacity 20–30%
Stroke: 1-2px
```

### 3. Chữ V cách điệu
Hình mũi tên hướng lên từ chữ V, dùng làm accent.
```
Màu: #0099CC hoặc #FFFFFF
Dùng ở góc hoặc làm icon accent
```

### 4. Shape phân cách (Divider Shape)
Đường cong hoặc góc cắt 15° phân cách vùng xanh và vùng trắng.
```
Thay vì đường thẳng ngang → dùng hình lượn sóng hoặc diagonal cut
```
